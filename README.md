# 🐦 Flying Bird

A simple Flying Bird game built using **HTML, CSS, and JavaScript**.

## 🎮 About

Flying Bird is a small browser-based game where the player controls a bird and tries to avoid obstacles.

The project was created to practice:

- JavaScript DOM manipulation
- Event handling
- Game logic
- CSS animations and styling
- Basic browser game development

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript


## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/CommenMan/flyingBird.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

That's it! 🎉
